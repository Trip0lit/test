# J'ai crée un média

Site vitrine d'un média consacré à l'actualité juridique française et aux entretiens avec les figures du droit.

Site statique (HTML/CSS/JS, sans dépendance) :

- `index.html` — page d'accueil : à la une, fil d'actualité, entretiens, rubriques, lettre d'information
- `interview.html` — modèle de page « grand entretien »
- `assets/styles.css` — styles (clair/sombre, responsive)
- `assets/main.js` — date du jour, formulaire de la lettre

Pour le voir : ouvrir `index.html` dans un navigateur, ou `python3 -m http.server`.

Les personnes et entretiens présents sont fictifs : ce sont des contenus d'exemple à remplacer.
